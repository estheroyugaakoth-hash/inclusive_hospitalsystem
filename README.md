
# Inclusive HealthCare — Hospital Management System

## Overview

Inclusive HealthCare is a web-based hospital management
system prototype designed to support patient account
management, appointment requests, and accessible interaction.

## Features

- Patient registration and login
- Password hashing using PHP
- Session-based patient authentication
- Appointment booking and management
- Appointment status updates and deletion
- Accessibility-focused interface
- Responsive web interface

## Technologies

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- PDO

## Local Setup

1. Install a PHP and MySQL development environment.
2. Place the project in the web server's project directory.
3. Create the `inclusive_healthcare` database.
4. Configure `config/database.php` with your local
   database connection details.
5. Create the patients table using the SQL provided.
6. Start the web server and MySQL.
7. Open the project through your local web server.

## Security and Limitations

This is a development portfolio project and is not
approved for storing real patient information.
Authentication and database integration must be tested
before deployment. Additional authorization controls,
secure deployment configuration, and medical-record
protections are required before real-world use.
